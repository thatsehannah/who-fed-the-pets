#  Who Fed The Pets?

An app that tracks who fed the pets last so they can have the meals they need every day.

## User Stories
- A user can create a household (making them the admin user for that household)
- An admin user can add and remove pets from a household
- An admin user can send requests to other users to add them to their household as either a member or guest
- An admin user can add standard users or guests to a household
- An admin user can create multiple feeding schedules for a household
- An admin user can edit or remove feeding schedules for a household
- An admin user can create multiple feeding intervals to add a feeding schedule
- An admin user can optionally appoint a user to a specific feeding interval
- An admin user can log when they feed the pet(s)
- A standard user can review the household they've been added to
- A standard user can optionally appoint themselves to a specific feeding interval
- A standard user can log when they've fed the pet(s)
- A standard user can create a household
- A standard user can remove themselves from a household
